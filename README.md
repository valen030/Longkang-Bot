
# LKG Discord Music Bot
A simple and user friendly Discord bot with the sole purpose of playing music.

## Features 

- Able to support Linux and Windows (refer [Wiki](https://github.com/valen030/Longkang-Bot/wiki)) 

## Commands
| Command | Description |
|---------|-------------|
| `join`, `j` | Join the channel |
| `leave`, `quit`, `go` | Leave the channel |
| `help`, `h`, `command` | List all the commands |
| `play`, `p` | Play a song |
| `playlist`, `pl` | Play a list of songs |
| `pause`, `pa`, `wait` | Pause current song |
| `resume`, `con`, `continue` | Resume current song |
| `skip`, `s`, `next` | Play next song |
| `playskip`, `ps` | Skip current track and play the requested track |
| `now`, `ct`, `current` | Current track |
| `loop`, `cycle` | Enable or disable loop on current track |
| `queue`, `q`, `l`, `list` | Show the queue |
| `shuffle`, `mix`, `sf` | Shuffle the queue |
| `clear`, `c` | Clear the queue |
| `remove`, `r` | Remove a track from the queue |

## Getting Started
### Using the Configuration Tool (For Window user)
1. Download the application at [Release](https://github.com/valen030/Longkang-Bot/releases), select according to your OS.
2. After download and extract the file, you will see a LKGBotConfiguration.exe.
3. Start it up and follow its steps.

- The only **requirement** is you need to have a Discord Bot _(it is quite easy to register one)_
- You can read more details in [Wiki](https://github.com/valen030/Longkang-Bot/wiki)
